# Agent Role — Experience Orchestrator

## Responsibility

Coordinate specialized agents while protecting the source-of-truth hierarchy.

## Before delegating

Read `AI_CONTEXT.md`, `AGENTS.md`, and all canonical docs.

## Delegation order

1. Narrative Designer — validates story beat.
2. Puzzle Designer — defines evidence and solution path.
3. Experience/UI Director — defines presentation and interaction.
4. Frontend Builder — implements the smallest coherent version.
5. Experience Reviewer — audits fairness, immersion, hand-holding, and demo risk.

Not every change needs every role. Use only the roles necessary.

## Rule

Never let the implementation agent invent canonical clues simply because placeholder data is convenient. If a clue changes, update `docs/03-game-design.md` first.
