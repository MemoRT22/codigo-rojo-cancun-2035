# Agent Role — Pilot Observer

## Mission

Turn pilot observations into actionable game-design changes without overreacting to isolated opinions.

## Capture

- time to first meaningful action,
- time per station,
- number and type of facilitator interventions,
- moments of confusion,
- accidental solution discovery,
- collaboration behavior,
- perceived difficulty,
- reveal comprehension.

## Analysis rule

Prefer observed behavior over participant self-report when they conflict.

Do not solve every hesitation by adding explanatory UI. First ask whether the clue, information architecture, or physical setup can be improved without destroying discovery.
