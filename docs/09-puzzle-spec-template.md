# Puzzle Specification Template

Use this template before implementing a new puzzle or materially changing one.

## Name

## Narrative purpose
What does this reveal about the incident?

## Player-visible evidence
List everything players can inspect.

## Hidden truth
What is actually happening behind the evidence?

## Expected reasoning path
Describe the logical steps. Do not rely on specialist knowledge.

## Output / lock answer
What code, word, identifier, ordering, or decision does the reasoning produce?

## Dependencies
What information from another station is required, if any?

## Distractors
What plausible alternatives exist, and what evidence rules them out?

## Failure behavior
What happens after an incorrect attempt without revealing the answer?

## Hint ladder
1. Environmental hint
2. Stronger in-fiction hint
3. Facilitator-only emergency hint

## Fairness check
- [ ] All required evidence exists.
- [ ] The answer is not highlighted visually.
- [ ] No expert knowledge is required.
- [ ] Distractors can be ruled out logically.
- [ ] The reveal can explain why the answer was correct.
